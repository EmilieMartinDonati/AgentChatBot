# Acme Outdoor Gear – Return Policy

_Last updated: March 2026_

## Return window

Customers can return any item within **30 days** of delivery for a full refund.
Members of the **Acme Trail Club** get an extended window of **60 days**.

## Condition of returned items

- Items must be unused, clean, and in their original packaging.
- Tents and sleeping bags that have been used outdoors **cannot** be returned, but may be covered by the warranty (see the Warranty Terms document).
- Footwear can be returned if it has only been tried on indoors. Check the soles for dirt before accepting.

## How a customer starts a return

1. The customer logs in and opens **My Orders**.
2. They select the item and the reason for return.
3. A prepaid return label is emailed within 1 hour.
4. The parcel must be dropped at any Colissimo point within 7 days of generating the label.

## Refunds

- Refunds are issued to the original payment method within **5 business days** after the warehouse receives the item.
- Original shipping fees are refunded only if the item was defective or we sent the wrong item.
- Return shipping is **free** for orders above €80, otherwise €5.90 is deducted from the refund.

## Exchanges

We do not process direct exchanges. The customer must return the item and place a new order.
Agents may offer a **10% discount code (ACMESWAP10)** to compensate when an exchange is requested for a sizing issue.
